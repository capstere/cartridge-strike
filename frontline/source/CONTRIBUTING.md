# Contributions

Ce dépôt est une copie publique du code de Cartridge Strike: Frontline, mise à jour de temps en temps. Le développement se fait ailleurs :
les pull requests ne sont pas reprises, et la copie suivante les écraserait. Pour signaler un problème ou proposer une idée, passez
par l'espace Communauté du jeu (https://capstere.github.io/cartridge-strike/frontline). Vous êtes libre de partir de ce code pour votre propre projet, selon
`LICENSE` et `NOTICE.md`.

This repository is a public copy of the Cartridge Strike: Frontline source code, refreshed from time to time. Development happens
elsewhere, so pull requests are not merged and the next copy would overwrite them. To report a problem or suggest an idea, use the
Community space in the game (https://capstere.github.io/cartridge-strike/frontline). You are free to start your own project from this code, under `LICENSE`
and `NOTICE.md`.
