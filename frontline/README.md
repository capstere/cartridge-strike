# Cartridge Strike: Frontline

Playable standalone FPS version using the published Riposte: Frontline 5.6.0 engine.
Play: [Frontline](./index.html) | Existing game: [Cartridge Strike](../fps/).

The original JavaScript, procedural maps, weapons, bots, combat, UI, mobile/gamepad controls and browser-to-browser PeerJS multiplayer are provided in source/.
An original brand, logos, app icons, OG preview and synthetic hit sound are substituted. Restricted music and Mixamo-derived animation clips are not redistributed. The game's procedural animation fallback is used. The official accounts, leaderboard, friend system and server-hosted public matchmaking are not in the upstream release. PeerJS online play requires an internet connection and a compatible browser.
